# Student-Management-System
The Student Management System is a simple desktop application that stores student information in a SQLite database. Users can add, search, update, delete, and display student records. The project uses Pandas to display data in a table format and perform basic analysis.

## Features

- Add Student
- View Students
- Search Student
- Update Marks
- Delete Student
- Student Statistics

## Technologies

- Python
- SQLite
- Pandas
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
